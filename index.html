About NexCore Study Hub

Independent,
community-powered,
review-minded.

NexCore Study Hub is an independent resource catalogue built for the SQU community — not an official Sultan Qaboos University service.

We keep a manual review process because quality matters more than quantity. Contributors stay responsible for sharing only what they are permitted to share.

Report a resource or request removal

Verified badge

When a resource appears as verified, it means a NexCore reviewer checked the catalogue details and the public Drive viewer link before publishing.

Manual review process

Every submission is reviewed before it can appear in the catalogue. No auto-publishing.

Community-driven

Built by students, for students. Contributors grow the catalogue; NexCore Labs keeps it organized.
